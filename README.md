# Finance Education

Desktop-приложение для изучения основ финансовой грамотности. Проект объединяет лекции, тесты, тренировочные задания и личную статистику пользователя в одном интерфейсе.

Приложение написано на Python с использованием PySide6 и QML. Данные хранятся в SQLite-базе `data/data_base/data.db`.

## Возможности

- регистрация и авторизация пользователей;
- хранение паролей в виде PBKDF2-SHA256-хэшей с солью;
- просмотр тем курса и лекционных слайдов;
- прохождение тестов по урокам;
- генерация тренировочных финансовых задач;
- проверка числовых и текстовых ответов;
- сохранение результатов тестов и тренажеров;
- просмотр статистики прогресса пользователя;
- отдельный редактор для добавления лекций, изображений и тестовых вопросов.

## Темы и задания

В проекте предусмотрены учебные материалы по базовым финансовым инструментам и расчетам. Тренажеры генерируют задачи на темы:

- инфляция и покупательная способность;
- прибыль и доходность акций;
- дивиденды;
- купонный доход и погашение облигаций;
- комиссии ETF;
- фьючерсы и гарантийное обеспечение.

## Технологии

- Python 3.11;
- PySide6 / Qt Quick / QML;
- SQLite;
- Qt Resource System для графических ресурсов.

## Установка

Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install PySide6
```

Если запускаете проект из уже созданного окружения, достаточно активировать `.venv`.

## Запуск приложения

```bash
python main.py
```

После запуска открывается splash screen, затем экран входа. Новый пользователь может зарегистрироваться, после чего становятся доступны главное меню, темы курса, тесты, тренажеры и статистика.

## Запуск редактора материалов

Редактор лекций и тестов находится в папке `others`:

```bash
python others/lecture_editor.py
```

Через редактор можно создать или обновить лекцию, добавить слайды с текстом и изображениями, а также сохранить тестовые вопросы с правильными и неправильными вариантами ответов.

## База данных

SQLite-база создается автоматически при запуске, если файла еще нет. Схема включает таблицы:

- `users` - пользователи и данные для проверки пароля;
- `lesson` - темы курса;
- `lesson_lecture` - слайды лекций;
- `lesson_question` и `lesson_question_answer` - вопросы и варианты ответов;
- `generated_test` и `generated_test_info` - созданные попытки тестов;
- `test_stat` - ответы пользователя;
- `training_template` - шаблоны тренажеров;
- `user_result` - агрегированные результаты пользователя.

## Ресурсы интерфейса

Изображения для QML подключаются через `qml_qrc.qrc` и скомпилированный файл `qml_qrc_rc.py`. При добавлении новых ресурсов в `.qrc` файл нужно пересобрать Python-модуль ресурсов.

Пример команды:

```bash
pyside6-rcc qml_qrc.qrc -o qml_qrc_rc.py
```
